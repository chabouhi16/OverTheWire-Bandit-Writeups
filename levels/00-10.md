# Bandit Levels 00 to 10 Walkthrough

---

# Level 00 -> Level 01

### Goal
Log in to the game server via SSH and retrieve the password stored in a file named `readme` in the home directory.

### Commands Used
- `ssh`
- `ls`
- `cat`

### Walkthrough
1. Connect to the OverTheWire Bandit server:
   ```bash
   ssh bandit0@bandit.labs.overthewire.org -p 2220
2. Password used:
```bash
bandit0.
```
List directory contents and read the target file:
```bash
bandit0@bandit:~$ ls
readme
bandit0@bandit:~$ cat readme
PASSWORD_HERE
```
>[!NOTE]
>Basic SSH authentication and reading standard text files.
# Level 01 -> Level 02

### Goal
Retrieve the password stored in a file named - located in the home directory.
Commands Used
- `ls`
- `cat`

### Walkthrough
Log in to bandit1.
```bash
ssh bandit1@bandit.labs.overthewire.org -p 2220
```
List the contents of the home directory:
```bash
bandit1@bandit:~$ ls
-
```
Read the contents of the file named -:
```bash
bandit1@bandit:~$ cat ./"-"
PASSWORD_HERE
```
>[!TIP]
>Standard commands interpret a standalone - as standard input (stdin). Escaping the filename using ./"-" or ./- forces cat to treat it as a file path instead of an option.
# Level 02 -> Level 03

### Goal
Retrieve the password stored in a file with spaces in its filename located in the home directory.
Commands Used
- `ls`
- `cat`
### Walkthrough
Log in to bandit2.
```
ssh bandit2@bandit.labs.overthewire.org -p 2220
```
List the contents of the home directory:
```bash
bandit2@bandit:~$ ls
--spaces in this filename--
```
Read the file containing spaces by surrounding the filename in double quotes (or using backslash escaping):
```bash
bandit2@bandit:~$ cat ./"--spaces in this filename--"
PASSWORD_HERE
```
[!NOTE]
In Linux Bash, spaces act as argument separators. To reference filenames with spaces or dashes, enclose the path in quotes ("./file name") or escape each space with a backslash (file\ name).
# Level 03 -> Level 04
### Goal
Retrieve the password stored in a hidden file inside the inhere directory.
-`ls`
-`cd`
-`cat`
### Walkthrough
Log in to bandit3.
ssh bandit3@bandit.labs.overthewire.org -p 2220
Navigate into the target directory:
```bash
bandit3@bandit:~$ cd inhere/
```
Standard ls shows no files. Use the -a flag with ls to display all hidden files (files starting with a dot .):
```bash
bandit3@bandit:~/inhere$ ls -lah
total 12K
drwxr-xr-x 2 root    root    4.0K Jun 24 14:59 .
drwxr-xr-x 3 root    root    4.0K Jun 24 14:59 ..
-rw-r----- 1 bandit4 bandit3   33 Jun 24 14:59 ...Hiding-From-You
```
Read the hidden file:
```bash
bandit3@bandit:~/inhere$ cat ./"...Hiding-From-You"
PASSWORD_HERE
```
[!NOTE]
In Linux, files and directories that begin with a dot (.) are hidden by default. The ls -a (or ls -lah) command reveals these hidden entities.
